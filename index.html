02 / GET SET UP

Install your signature

Copy the signature above, then follow the guide for your email app.

Gmail (Web)

Works with Google Workspace and personal Gmail.

  1. In Gmail, click Settings (gear) and select See all settings.
  2. Under General, find Signature.
  3. Click Create new and name it “KJC”.
  4. Paste your formatted signature into the box (Ctrl+V or ⌘+V).
  5. Select defaults for new emails and replies.
  6. Scroll down and click Save Changes.
Official Gmail help ↗

Microsoft Outlook (Web / New)

Works with Outlook on the web and the new Outlook app.

  1. In Outlook, go to Settings → Accounts → Signatures.
  2. Click Add signature and call it “KJC”.
  3. Paste the formatted signature (Ctrl+V or ⌘+V).
  4. Choose your default signature for new messages and replies.
  5. Click Save.
  6. Send yourself an email to confirm everything displays correctly.
Official Outlook help ↗
Using classic Outlook for Windows? Go to File → Options → Mail → Signatures → New. Paste the signature, pick your defaults, then select OK. Menus vary by version.
