# KJC Email Signature Generator

A static website for King's Junior Consulting members to create branded HTML email signatures. Includes a live preview, light/dark mode, copy/download, and Gmail/Outlook setup instructions. No login or backend.

## File structure

```text
├── index.html
├── styles.css
├── app.js
├── .nojekyll
├── assets/
│   ├── kjc-logo.png
│   ├── favicon.svg
│   ├── gmail.svg
│   └── outlook.svg
└── README.md
```
